# Legacy prototype (not deployed)

This folder holds the original **SahaShares** prototype (Express + MongoDB + Vite) exactly as it was. It was moved here with `git mv` when Dalali Trust was rebuilt on Next.js + PostgreSQL in the parent directory.

- It is **not** built, tested or deployed by the new application.
- It contains simulated payment and verification logic and endpoints without authorization. **Do not deploy it.**
- See `../docs/AUDIT.md` and `../docs/MIGRATION.md` for what was found and what replaced each feature.

The owners may delete this folder once they no longer need it for reference (and after any legacy data has been handled as described in MIGRATION.md).
